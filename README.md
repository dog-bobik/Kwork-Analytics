# Kwork Pulse

Локальный дашборд Kwork на FastAPI, async SQLAlchemy, React и PostgreSQL.

## Запуск

```bash
make up
```

После запуска откройте `http://127.0.0.1:8080` и войдите в Kwork через форму.
Файл `.env` для авторизации не используется. При подключении аккаунта сервер сохраняет профиль и зашифрованный Kwork API-токен. Пароль не записывается в PostgreSQL.

Также доступны:

```bash
make up frontend
make up backend
```

- frontend: `http://127.0.0.1:8080`
- backend API: `http://127.0.0.1:8081`
- PostgreSQL хранит пользователей, серверные сессии, актуальный кэш и снимки аналитики в Docker volume `kwork_postgres`.

Backend сам обновляет все подключённые аккаунты каждые 15 минут, даже если браузер закрыт. API страниц читает данные из PostgreSQL; при устаревшем кэше сервер автоматически запускает фоновую синхронизацию, а frontend показывает анимированные skeleton-карточки и ожидает результат.

Показатель «Сегодня» у кворка — разница между текущим количеством просмотров и первым снимком после полуночи по часовому поясу Asia/Yekaterinburg.
