# Аудит исходной библиотеки

Дата: 13 октября 2026 года.

Проверены все исполняемые Python-файлы исходной копии, модели, примеры, тесты,
workflow-файлы, зависимости и сетевые адреса.

Признаков намеренной кражи данных, телеметрии, запуска сторонних команд,
динамического выполнения кода или скрытой записи файлов не найдено. Код
обращался только к `api.kwork.ru`, `kwork.ru` и `notice.kwork.ru`.

Найденные риски:

- критично: `netloc.endswith("kwork.ru")` пропускал адрес вида `evilkwork.ru`;
- высоко: web-клиент принимал произвольные абсолютные URL и редиректы;
- высоко: API host можно было подменить через конструктор, направив секреты на
  другой сервер;
- средне: исключения сохраняли полный ответ сервера, потенциально попадающий в
  логи;
- средне: WebSocket debug-лог содержал полные тексты сообщений;
- низко: в `web_client.py` был двойной декоратор `@staticmethod`;
- лишняя поверхность: методы записи, загрузки файлов, сообщений и создания
  откликов не нужны для текущей задачи.

Новый клиент имеет фиксированный HTTPS-хост, запрещает абсолютные URL и
редиректы, не логирует секреты и поддерживает только `signIn` и `/offers`.
Исходная версия сложена в `_legacy/`. `LICENSE` сохранён по требованию MIT.
